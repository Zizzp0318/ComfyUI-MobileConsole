ComfyUI 手机控制台  使用说明
================================================

这是什么
------------------------------------------------
在电脑上跑一个小服务，手机浏览器打开就能：
  · 选工作流、填参数、点运行
  · 出图自动回到手机上

ComfyUI 始终在你电脑上跑，手机只是遥控器。
你的工作流、模型、自定义节点一个都不用搬。


准备工作
------------------------------------------------
1. 电脑上装好 ComfyUI，能正常出图
2. 装 Python 3.9 或更高版本（安装时勾选 Add Python to PATH）
3. ComfyUI 启动时要允许其他设备访问，加参数 --listen 0.0.0.0

   官方便携版这样启动：
     .\python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --listen 0.0.0.0

   秋叶绘世启动器：高级选项 → 额外参数里填 --listen 0.0.0.0


第一次使用
------------------------------------------------
1. 双击「启动控制台.bat」，弹出一个黑窗口，别关它
2. 浏览器会自动打开管理页 http://127.0.0.1:8899/admin
3. 点「导入 JSON」，选你在 ComfyUI 里用「导出(API)」得到的工作流文件
4. 勾选要在手机上出现的参数，可以改名、设默认值、用 ▲▼ 调顺序、填分类
5. 点「保存并生效」
6. 手机连同一个 Wi-Fi，打开黑窗口里显示的「局域网访问」地址


提示「没有找到可用的 Python」怎么办
------------------------------------------------
启动脚本会依次尝试：python.txt → runtime 文件夹 → py 启动器 → python 命令。

如果都失败，说明系统里没有能直接调用的 Python。三个办法：

  办法一：安装官方 Python（推荐）
    下载 python.org 的安装包，第一步务必勾选 "Add Python to PATH"。

  办法二：手动指定已装的 Python
    在本目录新建文本文件 python.txt，第一行写 python.exe 的完整路径，例如：
      C:\Python312\python.exe
    保存后重新双击启动即可。

  办法三：用便携版
    把便携版 Python 解压到本目录，文件夹命名为 runtime，
    也就是让 runtime\python.exe 存在。


在外网用（可选）
------------------------------------------------
电脑和手机都装 Tailscale，登录同一个账号。
黑窗口里会多出一行「外网(Tailscale)」地址，手机用它访问，在哪都能跑图。

注意：管理页只能用 127.0.0.1 或局域网地址打开。
手机打开 .../admin 会被拒绝，这是故意的——手机上只能跑图，不能改配置。


配置
------------------------------------------------
用记事本打开 config.json：

  comfy_url    ComfyUI 地址，默认 http://127.0.0.1:8188
               如果 ComfyUI 装在另一台电脑上，改成 http://那台机器的局域网IP:8188
  port         本服务端口，默认 8899。被占用时改成别的
  bind         监听地址，默认 0.0.0.0（所有网卡）。只给本机用可改 127.0.0.1
  open_admin   启动后是否自动打开管理页，默认 true

改完保存，重新双击启动即可。


文件说明
------------------------------------------------
启动控制台.bat   双击启动，关窗口即停止
server.py        服务本体
web/             手机端页面 + 管理页
api_workflows/   你的工作流都放这里
                 直接平铺，不用建子文件夹
                 .api.json 是工作流，.ui.json 是界面配置
config.json      配置
python.txt       可选，指定 python.exe 路径
.cache/          自动生成的节点信息缓存，删了会重建


常见问题
------------------------------------------------
窗口一闪就没了
  多半是没找到 Python。把窗口截图看清楚提示，或用上面的三个办法之一。

手机打不开页面
  1. 先确认手机和电脑在同一个 Wi-Fi
  2. 电脑防火墙：首次运行 Python 时会弹窗，要允许「专用网络」
  3. 确认 ComfyUI 启动时加了 --listen 0.0.0.0

参数识别不全 / 模型下拉框是空的
  ComfyUI 必须开着。管理页要在线读取节点定义和模型列表，
  ComfyUI 关着时只能识别出大概的类型。

点了运行没反应 / 报错
  先在电脑浏览器打开 http://127.0.0.1:8188 确认 ComfyUI 本身正常。

导入时提示「这不是 API 格式」
  ComfyUI 里要用「导出(API)」，不是普通的「保存」。
