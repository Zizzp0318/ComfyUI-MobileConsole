# ComfyUI 手机控制台

用手机浏览器操控家里电脑上的 ComfyUI 出图。

不是又一个 ComfyUI 客户端，而是一个**极简遥控器**：你在电脑上把工作流整理好，只挑出想调的几个参数（提示词、参考图、分辨率……），手机上就只看得到这几个。剩下的节点全部隐藏，不会因为手滑改坏工作流。

```
电脑：ComfyUI（照常运行，加 --listen 0.0.0.0）
  ↑
  │ 本地回环
  │
这个服务（8899）—— 手机浏览器打开就是遥控器
  ↑
  │ 局域网 / Tailscale
  │
手机：选工作流 → 填参数 → 点运行 → 看图
```

## 特性

- **只暴露你要的参数**：电脑端管理页勾选，手机端就只显示这些，其余全隐藏
- **深色毛玻璃界面**：手机端和管理页统一暗色玻璃质感，参数按「提示词 / 参考素材 / 画面与种子 / 高级」分区
- **手机端顺手**：工作流搜索与最近使用、画面比例直接点九宫格、运行中可中断、刷新不丢上次结果
- **参数每次回到默认**：手机上打开工作流总是显示管理页里配的默认值，不记上次手输的内容；跑出来的结果照常保留
- **长任务不怕断**：任务状态记在电脑端，手机锁屏、关页面、几小时后再打开都能看到结果，不再有「等 5 分钟就判超时」
- **管理页好用**：字段可拖拽排序、只看已选、按名称筛选、一键预览手机端效果
- **工作流原样提交**：读 API 格式 JSON，只替换你填的字段，自定义节点一个都不丢
- **自动随机种子**：每次运行换新种子，不会反复出同一张图
- **可视化配置**：导入工作流、勾参数、改显示名、设默认值、调顺序、分组，全在浏览器里点
- **下拉选项在线读取**：模型、LoRA、采样器直接选，不用手打路径；装了新模型点一下「刷新节点信息」就更新
- **手机端涂抹遮罩**：直接在参考图上涂要重绘的区域，服务端合成带 alpha 的 PNG 再交给 ComfyUI
- **访问令牌**：默认开启。手机第一次用启动窗口里带 `?t=` 的地址打开，之后自动记住，同网其他设备没有令牌进不来
- **Tailscale 友好**：在外网也能用，不需要公网 IP
- **几乎零依赖**：只用 Python 标准库；只有「涂抹遮罩」用到 Pillow（可选）
- **单文件 exe**：也可以打包成 exe，给别人用不用装 Python

## 快速开始

### 前提

1. 电脑上装好 ComfyUI，能正常出图
2. **ComfyUI 启动时必须加 `--listen 0.0.0.0`**，否则手机连不上

   官方便携版：

   ```bat
   .\python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --listen 0.0.0.0
   ```

   秋叶绘世启动器：高级选项 → 额外参数里填 `--listen 0.0.0.0`

### 方式一：直接跑源码（需要 Python 3.9+）

```bash
python server.py
```

启动后窗口会打印出可用地址：

```
  ComfyUI 手机控制台
  ----------------------------------------------
  ComfyUI 后端 : http://127.0.0.1:8188
  工作流目录   : ...\api_workflows
  本机管理页   : http://127.0.0.1:8899/admin
  局域网访问   : http://192.168.1.100:8899/?t=xxxxxxxx
  ----------------------------------------------
  手机第一次打开请用上面带 ?t= 的完整地址，之后会自动记住
```

浏览器会自动打开管理页，没打开就手动访问 `http://127.0.0.1:8899/admin`（本机回环地址不需要令牌）。

> **手机端地址要带 `?t=`**。这是默认开启的访问令牌，第一次打开后浏览器会记住 Cookie，之后直接用 `http://192.168.1.100:8899/` 也能进。不想要令牌就把 `config.json` 里的 `token` 改成 `""`（同网设备就都能操作了）。

### 方式二：下载 exe（不需要 Python）

到 [Releases](https://github.com/Zizzp0318/ComfyUI-MobileConsole/releases) 下载最新的 `*-exe.zip`，解压双击即可。

首次运行会在 exe 旁边自动生成 `config.json` 和 `api_workflows/`。

想自己打包的话：

```bash
pip install pyinstaller
pyinstaller --onefile --console --name "ComfyUI手机控制台" --add-data "web;web" server.py
```

产物在 `dist/`。

## 配置工作流

1. 在 ComfyUI 里调好工作流，用**「导出(API)」**（不是普通的「保存」）导出 JSON
2. 打开管理页 `http://127.0.0.1:8899/admin`
3. 点「导入 JSON」，选择刚才的文件
4. 在参数列表里勾选要暴露给手机的字段，可以改显示名、设默认值
5. 用 ▲▼ 调整手机上的显示顺序
6. 填一个分类名（同名即同组），保存

手机刷新页面就能看到。

> 管理页只允许本机（`127.0.0.1`）和局域网访问，手机打开 `/admin` 会返回 403。手机上只能跑图，不能改配置。

## 配置

首次运行自动生成 `config.json`：

| 键 | 默认值 | 说明 |
|---|---|---|
| `comfy_url` | `http://127.0.0.1:8188` | ComfyUI 地址。装在另一台机器上就改成 `http://那台IP:8188` |
| `port` | `8899` | 本服务端口 |
| `bind` | `0.0.0.0` | 监听地址。只给本机用可改 `127.0.0.1` |
| `open_admin` | `true` | 启动后是否自动打开管理页 |
| `token` | 首次运行随机生成 | 访问令牌。改成 `""` 关闭鉴权（只在自己完全信任的网络里这么干） |
| `verbose` | `false` | 改成 `true` 会在窗口里打印每个请求，排查问题用 |

> 令牌换了以后，手机需要重新用新的 `?t=` 地址打开一次。

## 在外网用

电脑和手机都装 [Tailscale](https://tailscale.com/)，登录同一账号。启动时窗口会多出一行「外网(Tailscale)」地址，手机用它就行（同样要带 `?t=` 打开一次）。

不需要公网 IP，也不用在路由器上开端口。

## 目录结构

```
server.py              服务本体（单文件，标准库）
web/index.html         手机端页面
web/admin.html         电脑端管理页
config.json            配置（首次运行生成）
api_workflows/         工作流，平铺存放
  xxx.api.json         ComfyUI 导出的 API 格式工作流
  xxx.ui.json          界面配置：暴露哪些字段、显示名、顺序、分类
.cache/                节点信息缓存（可删，会重建）
.state/                任务台账：最近几次运行的状态和输出文件（可删，删了不影响出图）
```

`api_workflows` 是**平铺**的，不用建子文件夹。分类和排序都写在各自的 `.ui.json` 里，跟磁盘位置无关。删掉 `.ui.json` 会回到自动识别状态。

## convert.py（可选，不参与服务运行）

ComfyUI 界面版的工作流（带节点坐标、分组、连线样式）不能直接提交给 API，
`convert.py` 用来把界面版批量转成 API 格式。

它**额外依赖 Playwright**，服务本身不需要：

```bash
pip install playwright
playwright install chromium
```

平时用 ComfyUI 自带的「导出(API)」就够了，这个脚本是给需要批量转换的场景准备的。
不用它的话，删掉也不影响任何功能。

## 实现说明

整个服务就一个 `server.py`，几个关键点：

- **工作流即模板**：把 API 格式 JSON 当模板读进来，只覆盖用户在手机上填的字段，然后 `POST /prompt` 提交
- **字段提取**：遍历所有节点输入，结合 `/object_info` 判断是文本、数字、下拉还是图片/视频。上传位不看字段名，而是看节点声明的 `image_upload` 标记、`IMAGE`/`VIDEO` 类型、候选文件扩展名，所以 `image`、`input_image`、`image1` 这些叫法都能认出来
- **代理问题**：所有对 ComfyUI 的请求走 `ProxyHandler({})` 直连，否则 Clash 这类系统代理会把 `127.0.0.1` 也劫持成 502
- **任务台账**：提交时记下 `prompt_id`，后台线程每 5 秒查一次 ComfyUI 的 history，跑完瞬间把输出文件列表落盘。ComfyUI 的 history 只在内存里、重启就没了，只有这份台账能跨重启记住结果；手机端每次打开只读台账，不依赖页面一直开着
- **节点信息缓存**：`/object_info` 结果存内存 + 磁盘，ComfyUI 关着时管理页也能打开；管理页的「刷新节点信息」会清空缓存重新拉
- **访问控制**：默认令牌保护（`?t=` / `X-Token` / Cookie 三选一），本机回环直接放行；管理接口额外限制只能本机或局域网
- **上传防护**：单个请求 64 MB 上限，文件名只取 basename 并过滤非法字符与扩展名

## 常见问题

**手机打开显示「需要访问令牌」**

说明这是第一次在这台设备上打开。回到电脑看启动窗口，复制那行带 `?t=` 的完整地址（`http://192.168.x.x:8899/?t=xxxx`）在手机浏览器打开一次，之后就不用了。

**模型下拉框是空的 / 新装的 LoRA 不出现**

ComfyUI 必须开着。管理页点一下「刷新节点信息」，缓存会重拉；还是空的就确认 ComfyUI 的 `/object_info` 能正常返回。

**跑完时手机锁屏了 / 把页面关了，结果还在吗**

在。任务状态和输出文件记录在电脑端的 `.state/jobs.json` 里，手机重新打开工作流会自动读出来——上面显示「上次的结果 · 今天 13:20」。任务在跑的时候打开，会显示「还在跑 · 已 X 分」和停止按钮。

**涂抹遮罩报「服务端缺少 Pillow」**

遮罩合成要用 Pillow。exe 版已经打包好了；源码跑的话 `pip install pillow`，不装也能用，只是没有涂抹遮罩这个功能。

**手机打不开**

1. 手机和电脑在同一 Wi-Fi
2. Windows 防火墙允许这个程序（首次运行会弹窗，勾「专用网络」）
3. ComfyUI 加了 `--listen 0.0.0.0`
4. 注意：exe 换过位置后，旧的防火墙规则会失效，需要重新允许

**出图报错**

先在电脑浏览器打开 `http://127.0.0.1:8188` 确认 ComfyUI 本身正常。

**用了 Clash 之类的代理**

程序内部已经对 ComfyUI 请求做了直连处理。如果你用命令行测试，记得加 `--noproxy '*'`。
