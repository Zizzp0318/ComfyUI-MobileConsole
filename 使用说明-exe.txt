ComfyUI 手机控制台（免安装版）
================================================

这是什么
------------------------------------------------
在电脑上跑一个小工具，手机浏览器打开就能：
  · 选工作流、填参数、点运行
  · 出图自动回到手机上

ComfyUI 始终在你电脑上跑，手机只是遥控器。
你的工作流、模型、自定义节点一个都不用搬。
不需要装 Python，运行库已经打包在这个 exe 里。


怎么用
------------------------------------------------
1. 把「ComfyUI手机控制台.exe」放到一个固定文件夹
   （别放在下载目录或临时目录，配置和工作流会存在它旁边）

2. 先确保 ComfyUI 已经开着

3. 双击 exe，弹出一个黑窗口，别关它

4. 浏览器会自动打开管理页 http://127.0.0.1:8899/admin
   没自动开就手动输这个地址

5. 点「导入 JSON」，选你在 ComfyUI 里用「导出(API)」得到的工作流文件

6. 勾选要在手机上出现的参数，可以改名、设默认值、用 ▲▼ 调顺序、填分类

7. 点「保存并生效」

8. 手机连同一个 Wi-Fi，打开黑窗口里显示的「局域网访问」地址

第一次运行会在 exe 旁边自动生成：
  config.json       配置文件
  api_workflows\    工作流都放这里


前提条件
------------------------------------------------
· 电脑上装好 ComfyUI，能正常出图
· ComfyUI 启动时要允许其他设备访问，加参数 --listen 0.0.0.0

  官方便携版这样启动：
    .\python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --listen 0.0.0.0

  秋叶绘世启动器：高级选项 → 额外参数里填 --listen 0.0.0.0


在外网用（可选）
------------------------------------------------
电脑和手机都装 Tailscale，登录同一账号。
黑窗口里会多出一行「外网(Tailscale)」地址，手机用它访问，在哪都能跑图。

注意：管理页只能用 127.0.0.1 或局域网地址打开。
手机打开 .../admin 会被拒绝，这是故意的——手机上只能跑图，不能改配置。


配置 config.json
------------------------------------------------
用记事本打开：

  comfy_url    ComfyUI 地址，默认 http://127.0.0.1:8188
               如果 ComfyUI 装在另一台电脑上，改成 http://那台机器的局域网IP:8188
  port         端口，默认 8899。被占用时改成别的
  bind         监听地址，默认 0.0.0.0（所有网卡）
  open_admin   启动后是否自动打开管理页，默认 true

改完保存，重新双击 exe。


常见问题
------------------------------------------------
杀毒软件报毒 / 直接删掉
  这是 PyInstaller 打包的常见误报（因为 exe 会解压自己的运行库）。
  加白名单或恢复文件即可。

窗口一闪就没了
  看提示内容。多半是端口被占用，改 config.json 里的 port。

手机打不开页面
  1. 手机和电脑在同一个 Wi-Fi
  2. 电脑防火墙：首次运行时会弹窗，要允许「专用网络」
  3. 确认 ComfyUI 启动时加了 --listen 0.0.0.0

参数识别不全 / 模型下拉框是空的
  ComfyUI 必须开着。管理页要在线读取节点定义和模型列表。

点了运行报错
  先在电脑浏览器打开 http://127.0.0.1:8188 确认 ComfyUI 本身正常。

导入时提示「这不是 API 格式」
  ComfyUI 里要用「导出(API)」，不是普通的「保存」。
